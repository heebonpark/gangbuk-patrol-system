근무표 · 순회감독 통합관리

PatrolOps

지사마다 따로 관리하던 근무표와 순회 일정을, 한 화면에서 확인하고 서명·확정까지 끝내는 시스템입니다.

지사별 로그인 자동 근무표 전자서명 PDF 한 장 출력
핵심 기능
패턴 기반 근무표
근무 패턴을 한 번 설정하면 달이 바뀌어도 자동으로 이어집니다. 연차·병가 등 예외만 그때그때 입력하면 됩니다.
근무시간 자동 집계
일근·석근·전일 등 근태유형별 시간을 자동으로 더해 월 합계를 보여주고, 기준을 넘으면 바로 표시됩니다.
전자서명
근무자가 화면에서 직접 서명해 근무표 확인을 마칩니다. 종이로 받아 보관할 필요가 없습니다.
근무표 확정 · 수정요청
지사가 근무표를 확정하면 임의 수정이 막히고, 이후 변경은 관리자에게 요청을 보내 처리합니다.
지사별 접근 제한
지사는 자기 지사 근무표만 보고 관리하며, 다른 지사 데이터는 볼 수 없습니다.
엑셀 · PDF 출력
근무표를 엑셀로 내려받거나, 한 장짜리 PDF로 바로 출력할 수 있습니다.
시작하기
1
접속
아래 주소로 접속합니다. 별도 프로그램 설치는 필요 없습니다.
2
로그인
소속 지사를 선택하고 비밀번호를 입력합니다. 비밀번호를 모르면 관리자에게 문의하세요.
3
근무표 확인 · 서명
근무표 관리 화면에서 이번 달 일정을 확인하고, 이상이 없으면 미리보기에서 서명하기로 확인 서명을 남깁니다.
