PatrolOps 사용법

지사 담당자와 관리자가 실제 화면의 메뉴·버튼 이름 그대로 따라 할 수 있도록 정리했습니다.

시작하기

로그인

  1. 1
    접속
    배포된 주소로 접속하면 로그인 화면이 먼저 나타납니다.
  2. 2
    지사 담당자
    지사 드롭다운에서 소속 지사를 선택하고 비밀번호를 입력한 뒤 로그인을 누릅니다. 로그인 후에는 근무표 관리 화면만 보이며, 다른 지사 데이터는 볼 수 없습니다.
  3. 3
    관리자
    관리자로 로그인을 체크하고 관리자 비밀번호를 입력합니다. 관리자는 전체 지사와 모든 메뉴에 접근할 수 있습니다.
  4. 4
    비밀번호를 모를 때
    비밀번호 칸 옆 눈 아이콘으로 입력 내용을 확인할 수 있습니다. 그래도 모르면 관리자에게 문의하세요. 5회 이상 틀리면 5분간 로그인이 잠깁니다.
참고. 이 로그인은 서버 없는 정적 페이지 특성상 오조작 방지용 접근 제한입니다. 실제 인사·급여 데이터를 다루기 전에는 관리자와 먼저 상의하세요.
지사 담당자 · 01

근무표 확인

근무표 관리 화면에서 이번 달 일정을 확인합니다.

화면 상단에서 지사·보기 모드(이번 달 전체 / 기준일 ±7일)·월을 선택합니다. 각 직원의 날짜별 칸은 기본적으로 자동(패턴 기반) 상태이며, 연차·병가 등 예외가 있는 날짜만 드롭다운에서 코드를 직접 선택하면 그 칸이 주황 배경으로 바뀌어 예외임을 표시합니다.

표 상단에는 이번 달 서명 미완료 인원이 자동으로 집계되어 표시됩니다.

지사 담당자 · 02

근무 패턴 설정

신규 직원이나 근무조가 바뀐 직원에게 사용합니다.

각 직원 이름 아래 프리셋 버튼을 누르면 그 시점부터의 반복 패턴이 자동으로 설정됩니다.

버튼패턴
야시작야 휴 휴 주 주 야 야 휴
주시작주 야 야 휴 휴 주 주 야
상시휴 휴 주 주 주 주 주
주주야휴숙숙주 주 야 휴 숙 숙

새 직원을 등록할 때도 하단 + 직원 추가 입력줄의 패턴 선택 드롭다운에서 같은 프리셋을 바로 지정할 수 있습니다.

지사 담당자 · 03

미리보기 · 서명

서명은 이 화면에서만 할 수 있습니다.

  1. 1
    미리보기 열기
    미리보기 버튼을 누르면 범례·결재란·근무시간 합계·서명란이 포함된 최종 문서가 아래에 나타납니다.
  2. 2
    내 이름 찾기
    표 위쪽 성명으로 찾기 검색창에 이름을 입력하면 해당 행으로 자동 스크롤·강조됩니다. 모바일에서는 성명·합계·서명 칸이 화면 좌우에 고정되어, 스크롤해도 항상 보입니다.
  3. 3
    서명하기
    본인 행의 서명하기 버튼을 눌러 나타나는 캔버스에 손가락(모바일)이나 마우스로 직접 서명하고 서명 저장을 누릅니다. 저장된 서명은 그 직원·그 달에 계속 남습니다.
  4. 4
    초과근무 확인
    합계(시간) 열이 기준치(월 240시간)를 넘으면 빨간색으로 표시됩니다.
지사 담당자 · 04

엑셀 · PDF 출력

엑셀로 출력은 현재 화면의 근무표를 그대로 엑셀 파일로 내려받습니다. PDF 출력은 A3 가로 용지 한 장에 맞춰 자동으로 축소해 인쇄/저장합니다 — 별도로 용지 크기를 맞출 필요가 없습니다.

지사 담당자 · 05

근무표 확정 · 수정 요청

  1. 1
    확정
    이번 달 입력이 끝나면 근무표 확정을 누릅니다. 확정하면 상단에 확정됨 표시가 뜨고, 이 지사에서는 더 이상 날짜 칸·프리셋·직원 추가/삭제를 직접 수정할 수 없습니다.
  2. 2
    수정이 필요하면
    확정 후 나타나는 수정 요청 버튼을 눌러 대상 직원(선택)과 요청 내용을 적어 보냅니다. 관리자가 확인 후 처리합니다.
주의. 확정 취소는 관리자만 할 수 있습니다. 잘못 확정했다면 관리자에게 요청하세요.
관리자 · 01

수정 요청 처리

운영 알림 · 자동검증 탭 ③ 근무표 수정 요청에서 지사가 보낸 요청 목록을 확인합니다. 필요하면 해당 지사·월의 근무표 확정을 취소하고 직접 수정한 뒤, 요청 항목의 처리완료로 표시를 눌러 마무리합니다.

관리자 · 02

비밀번호 관리

관리자 설정 탭 비밀번호 관리 카드에서 지사별 비밀번호와 관리자 비밀번호를 코드 수정 없이 바꿀 수 있습니다. 기본값으로를 누르면 기본 규칙(지사명+1234+!)으로 되돌아갑니다.

참고. 여기서 바꾼 비밀번호는 이 브라우저에만 저장됩니다 — 다른 관리자 기기와 자동으로 공유되지 않으니, 바꾼 뒤에는 담당자들에게 직접 전달해야 합니다.
관리자 · 03

지사 · 구역/호수 관리

관리자 설정 탭에서 지사 추가/삭제, 경비지도사 정보 수정을 할 수 있습니다. 직원 구역/호수 관리 카드에서는 지사를 선택해 소속 직원 전체의 구역/호수 값을 표로 보고 바로 수정할 수 있습니다 — 이 값이 근무표 미리보기에서 직원을 묶어 보여주는 기준입니다.

관리자 · 04

백업 · 복원

관리자 설정 탭 데이터 백업·복원에서 전체 데이터를 JSON 파일로 내려받거나, 이전 백업 파일을 업로드해 복원할 수 있습니다. 정기적으로 백업해두는 것을 권장합니다.

참고

근태유형 코드표

미리보기 범례에 표시되는 공식 코드와 시간 환산 기준입니다.

B석근14J공가8

D대체일근8L연차0

화면의 날짜별 입력칸은 관례상 주/야/휴/숙 등 약식 코드를 쓰지만, 합계(시간) 계산은 위 표의 시간값을 그대로 적용합니다 (주=A·8h, 야=B·14h, 휴·숙=K·0h 등).

참고

자주 묻는 질문

서명을 잘못 남겼어요.
서명 이미지를 다시 누르면 서명 창이 열립니다. 다시 그려서 저장하면 이전 서명을 덮어씁니다.
근무표를 확정했는데 취소하고 싶어요.
지사 로그인에서는 취소할 수 없습니다. 관리자에게 요청하거나, 관리자가 직접 확정 취소를 눌러야 합니다.
다른 지사 데이터가 안 보여요.
지사 로그인은 원래 자기 지사만 보이도록 설계되어 있습니다. 여러 지사를 봐야 하면 관리자 로그인이 필요합니다.
비밀번호를 5번 틀렸더니 잠겼어요.
5분 뒤 자동으로 풀립니다. 화면에 남은 시간이 표시됩니다.
데이터가 사라졌어요.
이 시스템은 이 브라우저(또는 연결된 GitHub 저장소)에만 데이터를 저장합니다. 브라우저 데이터를 지웠거나 다른 기기·브라우저로 접속하면 이전 입력이 보이지 않을 수 있습니다. 정기적으로 전체 백업 다운로드를 해두면 복구할 수 있습니다.
구체적인 화면 이름·버튼 문구는 실제 배포 버전과 다를 수 있습니다. 차이가 있으면 관리자에게 알려주세요.
