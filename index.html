통합 순회 일정 (표준 스키마)

"현장 실근무" 열은 근무표 관리 탭 데이터를 기준으로 자동 계산됩니다. 지도사·지사 목록은 관리자 설정 탭에서 바뀝니다.

지사별 근무표 (근태 로스터)

각 직원은 "반복 패턴 + 예외(연차 등)"로 관리됩니다. 다음 달로 넘어가도 패턴이 자동으로 이어지며, 예외만 새로 입력하면 됩니다.

주황 배경 = 예외(수동 수정) 확정됨

구역별 근무 공백 확인

구역/호수별로 "교대" 직원의 주 · 야 · 숙 담당이 하루도 빠짐없이 채워져 있는지 자동으로 확인합니다. 근무표 편집(위 표)은 구역/호수순으로 정렬되어 있습니다.

주당 · 분기 근로시간 모니터링

주(월~일) 64시간 초과 금지, 분기(13주) 평균 52시간 초과 금지 기준으로 입력과 동시에 자동 계산됩니다.
