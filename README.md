# gangbuk-patrol-system

경비지도사 순회감독 일정 · 근무표 통합관리 시스템 (샘플/코드 저장소)

## 실행 방법

- **Windows**: `근무표시스템_실행.bat`을 더블클릭하면 기본 브라우저로 바로 열립니다. 별도 설치·서버 없이 동작합니다(폰트·엑셀 라이브러리만 인터넷에서 불러오고, 데이터는 이 브라우저에만 저장됩니다).
- **그 외**: `index.html`을 브라우저로 직접 열면 됩니다.
- 로그인은 지사 선택 + 비밀번호(기본값: 지사명+1234+!), 관리자는 admin1234+! 입니다. 관리자 설정 탭에서 바꿀 수 있습니다.

## 중요 안내

- index.html 안의 근무표 시드 데이터는 전 지사(8개 지사, 인근 지점 통합 · 156명) 규모이며, 이름은 전부 마스킹되어 있습니다 (권O호, 신O균 등).
- 배치현장 주소, 순회 예정 시간, 연락처 뒷자리는 마스킹되어 있지 않습니다. 이 저장소는 현재 Public입니다.
- 실제 운영 데이터(실명, 정확한 순회 일정)는 이 저장소에 올리지 말고 로컬 파일 또는 Private 저장소에서만 관리하세요.
- index.html 을 열면 시스템이 실행되며, 기본적으로는 로컬(이 브라우저)에만 데이터가 저장됩니다.
- 최근 갱신: 지사별 로그인·근무표 확정/수정요청·전자서명·모바일 대응·Windows 실행 배치파일 추가.
