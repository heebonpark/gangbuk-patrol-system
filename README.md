# gangbuk-patrol-system

경비지도사 순회감독 일정 · 근무표 통합관리 시스템 (샘플/코드 저장소)

## 중요 안내
- index.html 안의 근무표 시드 데이터는 전 지사(17개 지사/지점) 156명 규모이며, 이름은 전부 마스킹되어 있습니다 (권O호, 신O균 등).
- 배치현장 주소, 순회 예정 시간, 연락처 뒷자리는 마스킹되어 있지 않습니다. 이 저장소는 현재 Public입니다.
- 실제 운영 데이터(실명, 정확한 순회 일정)는 이 저장소에 올리지 말고 로컬 파일 또는 Private 저장소에서만 관리하세요.
- index.html 을 열면 시스템이 실행되며, 기본적으로는 로컬(이 브라우저)에만 데이터가 저장됩니다.
- 최근 갱신: 전 지사 취합본 반영, 일괄 업로드 기능, 근무표 ±7일 뷰 추가.
